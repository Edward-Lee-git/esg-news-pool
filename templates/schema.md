# 리포트 렌더러 사용 설명

`render_report.py`는 **자료(JSON)를 넣으면 같은 모양의 HTML 한 장**을 만든다. 서체·색·크기·열 구조·라이트/다크는 코드 안의 CSS 한 벌로 고정되어 있어서, 리포트마다·날마다 모양이 달라지지 않는다. 표준 라이브러리만 쓴다.

```
python render_report.py 자료.json 결과.html            # 보는 기기의 라이트/다크 설정을 따름
python render_report.py 자료.json 결과.html --theme dark   # 미리보기용으로 고정
python render_report.py --css > report.css             # CSS만 꺼내 보기
```

## 최상위 필드

| 필드 | 필수 | 설명 |
|---|---|---|
| `title` | O | 페이지 제목(큰 제목, 탭 제목) |
| `kicker` | | 제목 위 작은 글씨 |
| `meta` | | 제목 아래 기간·수집 시각 줄 |
| `pills` | | 핵심 수치 알약 목록 |
| `issues` | | 핵심 이슈 목록 |
| `legend` | | (일반동향) 점 표시 설명 한 줄. 없으면 생략 |
| `mark_label` | | `mark` 점에 마우스를 올렸을 때 나오는 글자. 기본 "사업 관련" |
| `groups` | O | 그룹 카드 목록(확인 필요 후보도 그룹 하나) |
| `footer` | | `limit`(데이터 한계 한 줄), `verify`(검증 줄) |

## pills

`{"label": "환경 E", "value": "12 / 10", "cat": "e"}` — `cat`을 주면 그 색의 점과 연한 배경이 붙는다(없으면 흰 바탕).
`{"label": "링크 없음", "auto": "nolink"}` — 값이 자동 계산된다(링크가 없는 기사 전체 수, 확인 필요 후보 포함).

## issues

`{"title": "굵은 제목", "body": "뒤에 이어지는 설명"}` — `body`는 없어도 된다.

## groups

| 필드 | 설명 |
|---|---|
| `cat` | 색 구분. `e` 환경, `s` 사회, `g` 지배구조, `n` 공통·해당 없음·보도 없음·확인 필요 후보, `p` 글로벌, `a` 부정이슈 확인 |
| `title` | 그룹 제목 |
| `num` | (부정기사) 제목 앞 번호 `01` |
| `count` | 제목 옆 건수 설명. **없으면 틀이 자동 계산**(`N건`, `cols`가 `mark`이면 `N건 · 사업 관련 M건`) |
| `count_note` | 자동 계산된 숫자 뒤에 덧붙일 설명(예: `목표 10건 미달: 목록 내 해당 기사 부족`) |
| `head_chips` | 머리줄의 칩 `[{"text": "...", "kind": "alert 또는 sub"}]` |
| `cols` | `mark`(일반동향: '주요' 열 있음) 또는 `plain`(규제동향·부정기사) |
| `open` | 처음부터 펼칠지. 기본 `true`. 해당 없음·보도 없음 그룹은 `false` |
| `rows` | 기사 목록. 없으면 `note`만 표시 |
| `note` | 기사가 없을 때 보여줄 문장 |
| `more` | 기사 아래 접히는 설명 `{"label": "...", "text": "..."}` |

## rows (기사 한 줄)

| 필드 | 설명 |
|---|---|
| `title` | 기사 제목 |
| `url` | 원문 주소(`http`/`https`만 허용). **없으면 `null`** |
| `summary` | 요약(없으면 요약 줄을 만들지 않음) |
| `source`, `date` | 매체, 게재일 |
| `tags` | 분류 칩 `[{"text": "...", "kind": "sub 또는 biz"}]` |
| `needs_check` | `true`면 '확인 필요' 점선 태그가 붙는다 |
| `mark` | `true`면 '주요' 열에 점이 찍히고 그룹 맨 위로 올라온다(`cols`가 `mark`일 때) |

## 렌더러가 스스로 지키는 규칙

- `url`이 `null`인 기사는 **제목이 클릭되지 않고(일반 글자, 기본 커서) '링크 없음' 점선 태그가 자동으로 붙는다.**
- 분류 칸의 순서는 항상 **분류 칩 → 확인 필요 → 링크 없음**이다. 순서를 자료에서 정할 수 없다.
- `cols`가 `mark`인 그룹은 `mark`가 `true`인 기사가 위로 온다(그 안의 순서는 입력 순서 유지).
- 모든 글자는 HTML로 이스케이프된다. 제목이나 요약에 `<script>` 같은 것이 들어와도 글자로만 보인다.
- 링크는 `http`/`https`만 허용하고, 그 외(`javascript:` 등)는 오류로 멈춘다. 링크는 새 탭에서 열린다.
- `cat`이 정해진 값이 아니면 오류로 멈춘다(조용히 잘못된 색으로 나오지 않는다).

## 파일

| 파일 | 설명 | 공개 저장소에 올려도 되는가 |
|---|---|---|
| `render_report.py` | 렌더러 본체(CSS 포함, 회사 이름 없음) | **가능** |
| `report.css` | 렌더러가 쓰는 CSS를 꺼낸 것(참고용) | 가능 |
| `schema.md` | 이 문서 | 가능 |
| `sample_*.json`, `samples/*.html` | 오늘 실제 기사로 만든 예시 | **올리지 말 것**(회사명과 분석 내용이 들어 있음) |

## 알아둘 점

- 글꼴은 Google Fonts의 Noto Sans KR을 불러온다. 글꼴 서버에 접속하지 못하면 `Malgun Gothic` 등 기본 글꼴로 대신 보인다.
- 게시 페이지 규칙에 맞춰 스크립트·이미지·외부 스타일시트(글꼴 제외)를 쓰지 않는다. 그룹 접기는 브라우저 기본 기능(`details`)이다.
- 모바일 화면은 고려하지 않았다. 표는 760px 미만에서 가로로 스크롤된다.
